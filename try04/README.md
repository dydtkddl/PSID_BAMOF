# try04: BA-MOF + 2IP DFT Validation

## Project goal
This is `try04`, added to test the reviewer comment about dilute-limit validity at higher ionic liquid loading.
It evaluates the dissociation of [EMIM][TFSI] in BA-MOF for two ion pairs (2IP) and compares with 1IP reference data from try03.

## Quick start

```bash
# 1) Build structure files
cd try04/01_structure_preparation
python3 build_structures.py

# 2) Run CP2K geometry optimization for cluster (associated state)
cd ../02_calculations/BAMOF_2IP_cluster
bash ../run_cp2k_gpu.sh

# 3) Run CP2K geometry optimization for dissociated state
cd ../BAMOF_2IP_dissociate
bash ../run_cp2k_gpu.sh

# 4) Post-process
cd ../../03_postprocessing
python3 analyze.py
```

## Directory layout

- `01_structure_preparation/build_structures.py`
  - Builds:
    - `BAMOF_2IP_cluster_init.xyz`
    - `BAMOF_2IP_dissociate_init.xyz`
  - Writes results into `02_calculations/...`

- `02_calculations/`
  - `run_cp2k_gpu.sh`
    - Docker + CP2K runner with auto image detection
    - Restart detection via `*.restart`
  - `BAMOF_2IP_cluster/input.inp`
    - 192 atom system (MOF: 158 + second EMIM+TFSI)
  - `BAMOF_2IP_cluster/BAMOF_2IP_cluster_init.xyz`
  - `BAMOF_2IP_dissociate/input.inp`
  - `BAMOF_2IP_dissociate/BAMOF_2IP_dissociate_init.xyz`

- `03_postprocessing/analyze.py`
  - Extracts final energy from CP2K outputs
  - Computes:
    - `E_cluster`
    - `E_dissociated`
    - `E_dississ = E_dissociated - E_cluster`
  - Checks latest 2nd IP EMIM-TFSI distance in dissociation trajectory
  - Writes `energy_comparison.csv`

- `docker/Dockerfile`
  - Base image: CP2K 2024.3 OpenMPI CUDA variant

## Numerical setup

- Cell vectors
  - `A = (16.000, -0.557, 0.090)`
  - `B = (-6.517, 14.613, -0.057)`
  - `C = (-4.635, -7.066, 13.095)`

- SCF/DFT
  - Functional: PBE + D3
  - Basis: DZVP-MOLOPT-SR-GTH
  - Method: GPW
  - `CUTOFF = 640`, `REL_CUTOFF = 40`
  - `EPS_SCF = 5.0E-7`
  - `MAX_SCF = 200`, `ADDED_MOS = 170`

- GEO_OPT
  - `MAX_ITER = 600`
  - `MAX_FORCE = 4.5E-4`
  - `RMS_FORCE = 3.0E-4`
  - `FIXED_ATOMS = 1..102`

## Key atom counts

- 1IP base structure: 158 atoms

- 2nd ion pair: 34 atoms (EMIM+19 + TFSI-15)
- Fixed MOF atoms: 102
- Unfixed MOF atoms: 22
- Added MOF + first ion pair + second ion pair: 192 total

## Reference dissociation energies from try03 (kJ/mol)

- Gas-phase: `225.06`
- MOF + 1IP: `23.05`
- BA-MOF + 1IP: `17.77`

`try04` target:
- BA-MOF + 2IP (new) is computed by `analyze.py` and compared against the above values.

## Notes

- `run_cp2k_gpu.sh` automatically checks for restart outputs and reruns using the latest restart file.
- If GPU image is missing, the script automatically falls back to CPU mode.
- A watchdog timer is built in with `--kill` seconds; defaults to 3600 seconds.
